# Simple Interest Calculator

A simple program to calculate simple interest using the formula:

**SI = (P × R × T) / 100**

Where:
- P = Principal amount
- R = Rate of interest (%)
- T = Time (in years)

## Example
If P = 1000, R = 5, T = 2:
SI = (1000 × 5 × 2) / 100 = 100

## Usage
Run the script and enter Principal, Rate, and Time when prompted to get the Simple Interest.
